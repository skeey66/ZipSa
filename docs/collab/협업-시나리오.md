## 누가 무엇을 올리나

| 순서 | 담당 | 브랜치 | manifest | 개수 | 범위 |

| 1 | BE1 | `backend` | `push-BE1.txt` | 56 | 인증·회원 · 커뮤니티·대출 |
| 2 | BE2 | `backend` | `push-BE2.txt` | 69 | 정책·뉴스 · 공공임대·실거래가 · 크롤러 |

| 5 | FE2 | `frontend` | `push-FE2.txt` | 15 | 정책·뉴스 · 매물·지도 |

**순서는 같은 브랜치 안에서만 지키면 됩니다** — `backend` 는 BE1 → BE2, `frontend` 는 FE1 → FE2.
뒷사람은 앞사람 것을 받고(`git pull --rebase`) 올립니다. `ai` 는 혼자 쓰므로 아무 때나 올려도 됩니다.
`frontend/src/views/ContractCheck*.vue` 2개는 미완성이라 아무도 올리지 않습니다 (`제외-미완성.txt`).

## 마지막 — main 에서 합치기

백엔드 → AI → 프론트 순서입니다. AI 코드가 백엔드(`user` · `policy` · `news`)를 import 하고,
프론트가 그 API 와 `AiInsight.vue` 를 씁니다.

```bash
git checkout main && git pull origin main
git merge --no-ff backend
git merge --no-ff ai
git merge --no-ff frontend

cd backend && ./gradlew compileJava && cd ..
cd frontend && npm run build && cd ..

git push origin main
```

GitHub 에서 `backend → main`, `ai → main`, `frontend → main` PR 로 합쳐도 됩니다. 리뷰 코멘트가 남아 협업 기록으로는 그쪽이 낫습니다.
